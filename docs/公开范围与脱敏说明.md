# 公开范围与脱敏说明

本次为新建公开归档，不迁移原工作区Git历史。公开文件通过明确清单上传，不递归上传整个工作区。

## 发布内容

- 当下执行器及必要本地模块的脱敏快照。
- 根据已读方案、实施记录与纠正结论重新整理的公开说明。
- 配置字段结构示例、依赖说明、源码来源校验清单。
- 已知缺陷、研究边界和发布前静态检查记录。

## 排除内容

- 私钥、助记词、API key、token、密码、真实签名与授权文件。
- 真实钱包与账户绑定、服务器IP、SSH目标、个人绝对路径、通知webhook及群聊标识。
- state、SQLite、逐笔账本、日志、备份、归档、缓存、浏览器数据、个人对话和原工作区Git目录。
- 可自动启动或部署生产的工作流、真实service配置与凭证文件。

真实身份、部署标识、历史特例参数及敏感值使用空值或明确占位，不通过可逆编码隐藏。一般策略参数属于本次公开方案范围，保留其业务含义；实际配置文件只提供空值结构示例。代码逻辑不因脱敏而顺手修复；公开快照仍有已知实现风险。

## 校验口径

公开前检查所有候选文件的内容与文件名，核对凭证模式、账户与主机信息、绝对私有路径、原始账本/日志等禁入内容。源码校验和用于区分脱敏前后的版本，不是私钥或认证材料。静态语法检查不执行交易代码。

检查结果只能覆盖所检查文件与已知模式，不能承诺绝对不存在任何敏感信息。若复核发现具体问题，先修正候选副本后再发布；不把未脱敏副本提交到Git历史。

## 文档整理方式

公开方案是重新整理的备案说明，保留批准约束、纠正链和未实现边界；不是原始对话、原始报告或财务数据的逐字镜像。源码快照的具体来源和脱敏差异，以源码清单为准。
