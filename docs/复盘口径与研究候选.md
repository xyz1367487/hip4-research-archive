# 复盘口径与研究候选

截至2026年11月10日，北京时间。以下保留研究方法和候选机制；不发布账户逐笔流水、钱包身份或私有财务记录，也不提供预期收益率。

## 统一核算

- 交易净结果包括实际成交价格、单列费用，以及期初期末库存。滑点已经体现在成交价格时，不重复扣减。
- 配对merge按真实双腿、同一动作、等量数量统计，双腿份数不是配对数。
- 普通退出与到期Settlement分开；剔除某类交易是分类归因，不是“无故障版本本应怎样成交”的反事实模拟。
- 奖励需要锁定市场、问题或奖励家族与准确奖励期。finalized时间、paid时间与奖励期起止不能互相代替。
- 支付回执、官方final金额、链上到账与实验归属是不同证据。跨期到账不能按收到时间直接计给新run。
- 不同账本、备份和导入文件以原始交易身份去重，不累加累计state或重复carryforward。
- 当前余额和持仓只是快照，不能直接替代历史本金、资金占用积分或完整账户收益。

## 组合转换候选

HIP-4的问题（question）包含多个互斥结果，必须核对全部结果，包括可能的fallback。研究中已观察到：

1. 买入一个具名结果的No。
2. 通过negate转换为其他结果的Yes，其中可能包含不可独立交易的兜底权益。
3. 卖出可出售的具名结果Yes，保留残余权益。
4. 在条件合适时补齐一整组，再经问题合并释放组合价值。

应分别计算：买入支出、卖出净回款、实际费用、未售库存、残余权益取得成本与后续处置。转换回执显示的默认价格、名义额或closedPnl不能直接当USDC到账；默认成本分摊价也不是可卖市值。

已观察样本的现金优势很薄，价格舍入、执行延迟和部分成交可改变符号。残余权益不能未经核实估为零，也不能先按面值计利润。期初已有库存的历史成本缺失时，不能把后续补买与合并差额称为完整利润。

## 有效报价与库存管理候选

quote奖励与成交奖励分开评估。奖励门槛是资格，不是风险目标；不能为了维持计分而自动放大库存。报价应有事前定价依据，发生单边成交后按库存调整，不以固定周转次数代替经济判断。

历史研究读取的规则中，quote、maker-fill、taker-fill分属不同池；builder fee可为零不代表协议费用为零。费档、staking、奖励预算与竞争份额都有时点和账户差异，不能线性套用。

## 学习其他公开账户的边界

成交额榜不是盈利能力榜。需分别核对被动/主动成交、配对/未配对库存、结算、资产转换及同奖励期收入。某账户有真实奖励到账，不证明其周转盈利；局部亏损样本也不能替代完整历史损益。

公开成交接口存在条数与留存限制。触及上限必须分页去重；空返回不能独自证明不存在更早成交。缺少历史库存、非成交动作和资金流时，明确保留核算缺口。
