# HIP-4 自动化交易研究与暂停版本备案

截至 **2026年11月10日（北京时间）** 的脱敏方案与源码快照，用于版本保存、备案和研究复核。

## 状态与版本边界

- 原自动化保持暂停、自启动禁用。这里记录的是备案时核查到的指定服务状态与运维约束，不是对所有进程、账户敞口或读者环境的检测。
- `src/` 保存既有执行器及其必要本地模块，**保留已知缺陷，未在归档过程中修复策略或恢复交易**。
- 跨结果转换、有效报价奖励和库存管理属于最新研究候选，未作为新的生产策略实现或部署。
- 公开备案不承接历史交易授权，不包含真实凭证，也不附带自动运行或部署工作流。

## 保留和排除

保留策略算法、一般风险约束、通用参数和已知缺陷。历史总占款、单市场限额及等待时间等作为**方案参数**说明，不代表本金、个人账户余额或新增执行授权。

不发布真实私钥、API key、认证令牌、钱包绑定、服务器定位、通知标识、实际授权、运行state、数据库、逐笔账本、日志、备份、浏览器数据或个人对话。未迁移原工作区Git历史。

除身份占位外，还对历史恢复特例参数、可关联事故的注释、私人资金背景和实际服务标识进行了脱敏。**这些替换会改变身份校验、历史匹配、报价或服务管理目标，不能将公开副本称为可直接运行或与原环境行为等价的系统。**

## 研究口径

1. 配对合并、普通退出、单边到期结算与奖励分别核算，交易额不等于利润。
2. 资产转换的账面损益不直接等同于USDC回款，残余权益须单列。
3. 奖励以同一市场、同一奖励期与完整成本比较，不用累计奖励抵扣任意区间交易。
4. 历史样本、当前快照、条件测算和未知假设分别表达；测试通过不等于策略有效。
5. 不以停摆期间偶然获利的单边结算，证明原定做市策略有效。

## 验证边界

源码经过不执行项目代码的AST解析、内存编译、依赖与摘要核对。没有在本次备案中安装依赖、运行真实执行器、重新执行完整测试或验证实盘收益。外部SDK及其全部传递依赖未归档，不构成完整可复现环境。

发布前对公开候选做敏感信息模式检查和独立范围复核，具体结论以审查记录为准；这不是完整漏洞审计或绝对无泄露保证。
